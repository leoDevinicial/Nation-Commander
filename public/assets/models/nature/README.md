# Nature Kit (Gobkit)

Modelos low-poly de arbustos, rochas e penhascos do
[Gobkit Free 3D Assets](https://github.com/Ariescar/gobkit-free-assets), licença **CC0 1.0**
(domínio público — ver `LICENSE-CC0.txt`). Atribuição não é exigida; crédito: "Nature Kit by Gobkit — https://gobkit.com".
Usados apenas como decoração do terreno; sem eles o jogo cai para geometria procedural. As árvores são procedurais (`src/game/render/Trees.ts`).
